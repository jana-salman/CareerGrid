Fix the Buy Now Button

The button's HTML is correct, but the JavaScript looks for the wrong id and runs before checking that the element exists. Update the script so it selects the correct button, initializes safely, verifies the element, and attaches the checkout click handler. Then run the tests.

Issue FE-4021 · product.js

Product page HTML (read only)

<button id="buy-now-btn" class="buy-now">Buy Now</button>
<section id="checkout-panel" class="checkout" hidden>
    <!-- checkout form -->
</section>

product.js

Select '#buy-now-btn', wrap the code in a DOMContentLoaded handler (or use defer), check that the element exists before calling addEventListener, and keep the click handler.

Guided fix 
document.addEventListener('DOMContentLoaded', function () {
    const buyNowButton = document.getElementById('buy-now-btn');

    if (buyNowButton) {
        buyNowButton.addEventListener('click', openCheckoutPanel);
    }
});
