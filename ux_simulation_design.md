# CareerGrid UX Designer Simulation

## Position
Junior UX Designer

## Simulation Theme
An e-commerce company is experiencing a high checkout abandonment rate.

## Main Story
The user starts the workday as a Junior UX Designer and receives several workplace emails.

An urgent message from the Product Manager reports that many users are abandoning the checkout process.

The user must prioritize the issue, investigate user research and analytics, identify the main UX problem, improve the checkout user flow, test the proposed solution, and communicate the final recommendation to the product team.

---

## Task 1: Inbox Prioritization

### Application
CareerGrid Mail

### Scenario
The user opens the workplace inbox and sees several emails.

One email from the Product Manager reports an urgent increase in checkout abandonment.

Other emails contain normal workplace messages and lower-priority requests.

### User Actions
The user must:

- Open and inspect emails.
- Determine which email is most urgent.
- Choose the correct first action.
- Write a professional reply.

### Interactive Elements
- Clickable email list.
- Email detail panel.
- Priority selection.
- First-action selection.
- Reply text area.
- Submit response.

### Skills Evaluated
- Prioritization
- UX judgment
- Communication
- Product thinking

---

## Task 2: User Research Investigation

### Application
UX Research Workspace

### Scenario
The Product Manager asks the UX Designer to investigate why users abandon checkout.

The user receives multiple evidence sources.

### Evidence Sources
- Product analytics
- User interview notes
- Usability test observations
- Customer support feedback
- Current checkout user flow

### User Actions
The user must:

- Open evidence sources.
- Analyze user behavior.
- Identify the primary friction point.
- Select supporting evidence.
- Write a short research finding.

### Core Problem
Users are being forced to create an account before completing payment, causing significant checkout abandonment.

### Interactive Elements
- Clickable evidence cards.
- Analytics panel.
- Interview transcript.
- User feedback.
- Current user-flow visualization.
- Problem selection.
- Evidence selection.
- Research finding field.

### Skills Evaluated
- UX research
- Analytical thinking
- Evidence-based decision making
- Problem identification

---

## Task 3: User Flow Redesign

### Application
CareerGrid Flow Builder

### Scenario
After identifying the checkout problem, the UX Designer must improve the user flow.

### Current Flow
Cart → Shipping → Create Account → Payment → Confirmation

### User Actions
The user must construct a better checkout flow using available steps.

Available steps may include:

- Cart
- Shipping
- Create Account
- Guest Checkout
- Sign In
- Payment
- Order Confirmation
- Newsletter Signup

### Expected Improvement
The redesigned flow should allow users to continue as guests instead of forcing account creation.

### Interactive Elements
- User-flow cards.
- Reordering controls.
- Add/remove flow steps.
- Test Flow button.
- Flow feedback.
- Design reasoning field.

### Skills Evaluated
- Information architecture
- User-flow design
- Problem solving
- UX decision making

---

## Task 4: Usability Testing

### Application
Usability Testing Lab

### Scenario
The redesigned checkout flow is tested with multiple simulated users.

### Participants
The simulation includes different user types such as:

- First-time mobile shopper
- Returning desktop customer
- First-time desktop shopper

### User Actions
The user must:

- Run usability tests.
- Inspect participant behavior.
- Identify remaining usability issues.
- Decide whether the design is ready or requires another iteration.

### Interactive Elements
- Participant cards.
- Run Test buttons.
- Completion time.
- User observations.
- Success/failure indicators.
- Release decision.

### Skills Evaluated
- Usability testing
- Observation
- Iterative design
- UX validation

---

## Task 5: Product Team Handoff

### Application
CareerGrid Team Chat

### Scenario
The UX Designer must communicate the investigation and proposed solution to the Product Manager and engineering team.

### User Actions
The user prepares a professional project update containing:

- Issue status
- Research findings
- Root cause
- User-flow changes
- Usability testing results
- Accessibility considerations
- Final recommendation

### Interactive Elements
- Structured handoff form.
- Message preview.
- Team-chat interface.
- Send Update button.

### Skills Evaluated
- UX communication
- Stakeholder communication
- Documentation
- Product collaboration
