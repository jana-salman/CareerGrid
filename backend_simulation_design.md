# CareerGrid Backend Developer Simulation

## Position
Junior Backend Developer

## Simulation Theme
A production login issue appeared after a new deployment.

## Main Story
The user starts the workday and receives an urgent message explaining that customers cannot log in.

The user must investigate the issue, review the related backend code, respond to the production incident, and communicate the final result to the team.

---

## Task 1: Inbox Prioritization

### Application
CareerGrid Mail

### Scenario
The user opens the workplace inbox and sees several emails.

One email reports an urgent production login failure.

### AI Generates
- Email sender
- Email subject
- Email body
- Email priority
- Four additional non-urgent emails
- Available actions

### User Can
- Open emails
- Read email content
- Arrange emails by priority
- Choose the first task to handle
- Write a professional reply

### Data Saved
- Emails opened
- Priority order
- Selected first action
- Written reply

### Skills Evaluated
- Prioritization
- Communication
- Professionalism
- Urgency recognition
